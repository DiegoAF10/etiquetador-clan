# Etiquetador · Clan Cervecero

Programa de escritorio para imprimir las etiquetas complementarias de registro sanitario en la impresora TSC TE200.

Este repositorio solo publica el instalador. El código vive en el repositorio privado de Clan.

## Instalar

1. Baje **[EtiquetadorClan.exe](https://github.com/DiegoAF10/etiquetador-clan/releases/latest/download/EtiquetadorClan.exe)**.
2. Ábralo. Si Windows muestra «Windows protegió su PC», toque **Más información** y luego **Ejecutar de todas formas**.
3. Queda el ícono **Etiquetador Clan** en el Escritorio.

## Actualizar

No hay que hacer nada: cada vez que se abre, el Etiquetador revisa si hay una versión nueva y se actualiza solo.
Los productos, ajustes, insumos e historial de cada computadora no se tocan.

## Requisitos

Windows 10 u 11 y la impresora TSC instalada por USB. No necesita instalar nada más.
La conexión con Odoo se activa con un código que entrega Clan Cervecero; el instalador no trae ninguna llave.
